# Redes Neuronales y Deep Learning

Repositorio con los trabajos prácticos de la materia **Redes Neuronales / Deep Learning**, enfocados en clasificación multiclase de texto sobre el dataset **20 Newsgroups** utilizando PyTorch, Optuna, MLflow y TensorBoard.

## Estructura del Repositorio

```text

├── TP2/
│   └── 02_MLP_20Newsgroups.ipynb          # Perceptrón Multicapa (MLP), funciones de activación, pruning y comparación con Softmax

│   └── 03_Regularizacion_MLP.ipynb        # Estudio comparativo de L1, L2, Dropout y Batch Normalization
